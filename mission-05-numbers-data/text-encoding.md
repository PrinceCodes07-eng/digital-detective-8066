# Task 5.4 - Text Encoding

## ASCII Values

- Uppercase A = 65
- Lowercase a = 97

## Why is an Encoding Standard Needed?

Computers store information as numbers. Encoding standards assign numbers to characters so different computers can store, send, and understand text consistently.

## Character Not in Basic ASCII

Hindi character: अ

Basic ASCII supports only 128 characters, so it cannot represent this Hindi character. Unicode, commonly encoded using UTF-8, supports it.
