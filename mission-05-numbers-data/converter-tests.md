# Number Converter - Test Results

I tested the number converter with three positive decimal numbers.

| Decimal Input | Binary Output | Hexadecimal Output |
|---|---|---|
| 13 | 0b1101 | 0xd |
| 25 | 0b11001 | 0x19 |
| 42 | 0b101010 | 0x2a |

## Python Functions Used

- `input()` - Takes input from the user.
- `int()` - Converts input into an integer.
- `bin()` - Converts a decimal number into binary.
- `hex()` - Converts a decimal number into hexadecimal.
- `print()` - Displays the output.

All three test cases produced the expected results.
