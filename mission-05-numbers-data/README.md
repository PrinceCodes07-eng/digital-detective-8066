# Mission 5 – Numbers and Data

## Objective
Learn how decimal, binary, and hexadecimal number systems work, verify conversions using Python, and build a number converter.

## Tasks Completed

### 1. Manual Conversions
- Decimal to binary
- Binary to decimal
- Hexadecimal to decimal
- Binary to hexadecimal

See `manual-conversions.md` for calculations.

### 2. Python Verification
Verified number conversions using Python's built-in functions.

See `python-verification.md` for expressions and results.

### 3. Number Converter
Created `number_converter.py` to:
- Accept a decimal number from the user.
- Convert it into binary using `bin()`.
- Convert it into hexadecimal using `hex()`.
- Display all results using `print()`.

Tested successfully with 13, 25, and 42.

See `converter-tests.md` for test results.

### 4. Text Encoding
Studied ASCII values and why encoding standards are needed.

- ASCII value of uppercase A: 65
- ASCII value of lowercase a: 97
- Example of a character outside basic ASCII: अ

See `text-encoding.md` for notes.

## Commands and Python Functions Used

- `python3` – Run Python programs.
- `input()` – Accept user input.
- `int()` – Convert input into an integer.
- `bin()` – Convert decimal to binary.
- `hex()` – Convert decimal to hexadecimal.
- `print()` – Display output.
