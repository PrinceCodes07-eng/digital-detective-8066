# Mission 5 — Numbers and Data

## Objective

This mission was about practising number-system conversions and using Python to check them.

## What I explored / practised

I worked on decimal-to-binary, binary-to-decimal, hexadecimal-to-decimal and binary-to-hexadecimal conversions. I checked conversions with Python and made `number_converter.py`, which takes a decimal input and displays binary and hexadecimal using `bin()` and `hex()`. I tried it with 13, 25 and 42. I also looked at ASCII values (A = 65 and a = 97) and a character outside basic ASCII, अ. Supporting notes include manual conversions, Python checks, test results and text encoding.

## What I learned and difficulties

I initially tried to enter a Terminal command in the Python prompt. I exited the Python interpreter with `exit()` and then ran the command in Terminal. This helped me distinguish the two environments and understand how Python can be used to verify conversions.

## Conclusion

This mission helped me connect the concepts I was reading about with commands or small examples I could try myself.
