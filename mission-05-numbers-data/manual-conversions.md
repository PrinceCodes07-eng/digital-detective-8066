
# Mission 5 - Manual Number Conversions

## 1. Convert Decimal 13 to Binary

Divide repeatedly by 2:

13 / 2 = 6 remainder 1
6 / 2 = 3 remainder 0
3 / 2 = 1 remainder 1
1 / 2 = 0 remainder 1

Read remainders from bottom to top.

Answer: 1101 (Binary)

## 2. Convert Decimal 25 to Binary

25 / 2 = 12 remainder 1
12 / 2 = 6 remainder 0
6 / 2 = 3 remainder 0
3 / 2 = 1 remainder 1
1 / 2 = 0 remainder 1

Answer: 11001 (Binary)

## 3. Convert Binary 1010 to Decimal

(1 x 2^3) + (0 x 2^2) + (1 x 2^1) + (0 x 2^0)

= 8 + 0 + 2 + 0

Answer: 10 (Decimal)

## 4. Convert Binary 1101 to Decimal

(1 x 2^3) + (1 x 2^2) + (0 x 2^1) + (1 x 2^0)

= 8 + 4 + 0 + 1

Answer: 13 (Decimal)

## 5. Convert Hexadecimal A to Decimal

A = 10

Answer: 10 (Decimal)

## 6. Convert Hexadecimal 1F to Decimal

F = 15

(1 x 16^1) + (15 x 16^0)

= 16 + 15

Answer: 31 (Decimal)

## 7. Convert Binary 1111 to Hexadecimal

1111 (Binary) = 15 (Decimal)

15 in hexadecimal = F

Answer: F (Hexadecimal)
