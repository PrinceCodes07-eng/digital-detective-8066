# Mission 2: Terminal and File Management

## Objective
Learn basic Linux terminal commands and understand file and directory management.

## 1. Directory Navigation
- `pwd` – Display current directory.
- `ls` – List files and folders.
- `ls -la` – Show all files, including hidden files.
- `cd` – Change directory.

## 2. File and Directory Management
- `mkdir` – Create a directory.
- `touch` – Create an empty file.
- `cp` – Copy files.
- `mv` – Move or rename files.
- `rm` – Remove files.

## 3. Finding and Searching
- `find` – Search for files by name.
- `grep` – Search for text inside files.
- `grep -r` – Search recursively.

## 4. File Permissions
- `chmod` – Change file permissions.
- `r` – Read (4).
- `w` – Write (2).
- `x` – Execute (1).

Examples:
- `chmod 644 file.txt`
- `chmod 755 script.sh`

## 5. Redirection and Pipes
- `>` – Write or overwrite file content.
- `>>` – Append content.
- `|` – Pass output from one command to another.
- `cat` – Display file contents.
- `echo` – Print text.

## 6. Practical Exercises
1. Created practice directories and files.
2. Copied and moved files using `cp` and `mv`.
3. Located files using `find`.
4. Searched file contents using `grep`.
5. Changed permissions using `chmod`.
6. Practised pipes and redirection.

## Conclusion
Successfully learned basic terminal commands, file management, searching, permissions, pipes, and redirection.
