# Mission 2 — Terminal and File Management

## Objective

I practised using the Terminal to move between directories, create and manage files, search, and change permissions.

## What I did / practised

Commands: `pwd`, `ls`, `ls -la`, `cd`, `cd ..`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `find`, `grep`, `chmod`, `cat`, `echo`, pipes (`|`), and redirection (`>` / `>>`). I learned that `find . -name "sharma"` searches for a file or folder name, while `grep "piece" file.txt` searches inside a file. `grep -r` searches inside files in a directory tree. Permission values: read=4, write=2, execute=1. Examples: `chmod 644 file.txt` and `chmod 755 script.sh`. I also tried `echo "Hello World" > notes.txt`, appending with `>>`, and `ls | grep ".txt"`.

## What I learned and difficulties

I made practice files such as `practice/demo.txt`, `practice/notes.txt`, `practice/test.sh`, and files under `practice/backup/`. At first I mixed up searching for a filename with searching for text inside a file. Practising both commands cleared it up. I also learned to double-check before using `rm`, because it deletes files.
