# Mission 3 — Operating Systems

## Objective

I looked at what an operating system does and how it handles programs, memory, files, and devices.

## What I explored / practised

An OS manages hardware and software resources and gives applications services. Examples include macOS, Windows, Linux, Android and iOS. I noted the difference between the kernel (the core that manages resources) and the shell (where I enter commands). A program is stored instructions; a process is that program while it is running. I reviewed PID, scheduling, multitasking and context switching, and tried `ps`, `ps aux`, `echo $$`, `top` and `vm_stat`. I also read about RAM, memory allocation, virtual memory, file management, device management and drivers.

## What I learned and difficulties

The program-versus-process distinction was confusing at first, but thinking of a program as the file and a process as its running instance helped. I also learned to press `q` to leave `top`. This mission helped me connect OS concepts with things I can actually observe in Terminal.

## Conclusion

This mission helped me connect the concepts I was reading about with commands or small examples I could try myself.
